# Orbit 星账 · 星空 Demo

高颜值纯视觉 Demo：繁星 + 星链 + 星轨，零依赖，双击即看。

## 运行

- 直接双击 `index.html` 用浏览器打开即可（无构建、无 npm）。
- 或本地服务：`npx serve .` / `python -m http.server` 后访问。

## 玩法

- 拖拽星体（失重漂浮 + 碰撞），悬停看关联（dim 其余 + tooltip）。
- 点击品类星体下钻「花销 × 标签」二部图，点其他星切换聚焦，`← 主视图` 返回。
- 底部星轨点击切换月份，两视图联动；`◉ 回到今天` 复位。
- 右侧光柱 / 鼠标滚轮切换粒度：日（花销全显）→ 月 → 年（只看星系）。
- 顶栏切换账本（生活费/私人）、维度（品类/情境，正交多维度演示）。
- `＋ 记一笔` 为装饰性玻璃浮层，保存会点亮一颗星（不持久化）。

## 结构

- `index.html` — 布局（顶栏/洞察面板/粒度轨/星轨/浮层）
- `styles.css` — 深空 + 玻璃拟态 + 辉光视觉
- `app.js` — 数据（编造）/ 星空背景 / 力导向图谱 / 星轨 / 交互

# 移动端 M0 · 布局与触控原型

> 这是 390×844 / 412×915 的**布局原型**，不是生产 UI。数据是演示数据，交互只做到“能打开/关闭账笺”，用于确认移动端信息架构和触控尺寸。
> 生产实现从 `web/` 的移动断点开始，不直接搬这份原型。

## 结论

当前桌面 UI 不能靠改 `max-width` 适配手机。移动端必须换交互模型：

- 不保留左读数柱 + 右校准轨；桌面骨架在手机上会让星图只剩很窄一条。
- 桌面读数收进**洞察账笺**；摘要条常驻星图底部，点开看完整 TOP / 交叉洞察。
- 星轨保留在底部，成为横向可拖的“时间尺”；底部导航只放 3 个入口。
- 记一笔是**全屏账笺**，不是居中弹窗。
- 触控目标≥44px；处理安全区、软键盘和 Android 返回键。

## 屏幕

### 主视图

- 顶栏 56px：品牌印、账本/月份、洞察入口（44px）。
- 星图占剩余高度；拖拽平移、双指缩放。
- 底部摘要条：结余 + 支出/收入，点开查看完整读数。
- 星轨 126px：横向时间尺，月份/今天可点。
- 底部导航 58px：星图 / 洞察 / ＋记一笔。

### 洞察账笺

- 从底部升起，最高 78%。
- 结余、支出、收入、环比、记录天数、TOP5、交叉洞察。桌面面板有的字段都在。
- 关闭 ×、点遮罩关闭；Android 返回键同样先关账笺。

### 记一笔账笺

- 94% 高，顶栏仍露出；字段滚动，底部保存固定。
- 支出/收入、金额、品类、情境、日期、账本、备注、取消/保存。
- 主 tag 选中后的细分区沿用桌面逻辑，在账笺内展开；不另做一套。

## 触控

| 区域 | 操作 |
|---|---|
| 星图 | 单指拖拽平移；双指 pinch 缩放；点节点下钻；长按/悬停看关联 |
| 星轨 | 横向拖拽换时间窗；点月份/今天切换 |
| 摘要条 | 点开洞察账笺 |
| 账笺 | 下滑关闭；点遮罩关闭；返回键关闭 |
| 星图缩放 | 双指；不占用桌面滚轮语义 |

- 触控目标：顶栏按钮/账笺关闭 44px，chip 44px，底部导航 48px，星轨节点 44×48px。
- 安全区：顶栏 `safe-area-inset-top`，底部导航/账笺 `safe-area-inset-bottom`。
- 软键盘：记一笔账笺在键盘弹出时保持输入可见，保存按钮可滚到。
- 横屏：不强行支持完整双栏；先保证竖屏可用，横屏做只读/简化视图。

## 信息不减少

移动端只是**重新组织**，不删除：

- 桌面左栏的全部读数 → 洞察账笺。
- 桌面右轨的缩放 → 双指缩放 + 星轨拖动。
- 桌面顶栏的账本/月份/记一笔 → 顶栏 + 底部导航。
- 桌面星轨的点击/拖动/今天 → 移动星轨相同。
- 桌面记一笔的全部字段 → 移动账笺。

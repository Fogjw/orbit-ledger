# 移动端 M0/M1 · 布局与触控

> M0 是 390×844 / 412×915 的**布局原型**，硬编码演示数据，用于确认信息架构；M1a 已把主视图骨架落到生产 `web/`（760px 断点），桌面布局不变。
> M1a 仍不是完整移动端：顶栏紧凑化、安全区、更多浮层适配在 M1b。

## 结论

当前桌面 UI 不能靠改 `max-width` 适配手机。移动端必须换交互模型：

- 不保留左读数柱 + 右校准轨；桌面骨架在手机上会让星图只剩很窄一条。
- 桌面读数收进**洞察账笺**；结余条放在顶栏下方，常驻星图上方，点开看完整 TOP / 交叉洞察。
- 星轨保留在底部，成为横向可拖的“时间尺”；底部导航只放 3 个入口。
- 记一笔是**全屏账笺**，不是居中弹窗。
- 触控目标≥44px；处理安全区、软键盘和 Android 返回键。

## 屏幕

### 主视图

- 顶栏 56px：品牌印、账本/月份、洞察入口（44px）。
- 星图占剩余高度；拖拽平移、双指缩放。
- 顶部结余条（54px）：结余 + 支出/收入，点开查看完整读数。
- 星轨 126px：横向时间尺，月份/今天可点。
- 底部导航 58px：星图 / 洞察 / ＋记一笔。

### 洞察账笺

- 从底部升起，最高 78%。
- 结余、支出、收入、环比、记录天数、TOP5、交叉洞察。桌面面板有的字段都在。
- 关闭 ×、点遮罩关闭；Android 返回键同样先关账笺。

### 记一笔账笺

- 94% 高，顶栏仍露出；字段滚动，底部保存固定。
- 支出/收入、金额、品类、情境、日期、账本、备注、取消/保存。
- 主 tag 选中后的细分区沿用桌面逻辑，在账笺内展开；不另做一套。

## 触控

| 区域 | 操作 |
|---|---|
| 星图 | 单指拖拽平移；双指 pinch 缩放；点节点下钻；长按/悬停看关联 |
| 星轨 | 横向拖拽换时间窗；点月份/今天切换 |
| 顶部结余条 | 点开洞察账笺 |
| 账笺 | 下滑关闭；点遮罩关闭；返回键关闭 |
| 星图缩放 | 双指；不占用桌面滚轮语义 |

- 触控目标：顶栏按钮/账笺关闭 44px，chip 44px，底部导航 48px，星轨节点 44×48px。
- 安全区：顶栏 `safe-area-inset-top`，底部导航/账笺 `safe-area-inset-bottom`。
- 软键盘：记一笔账笺在键盘弹出时保持输入可见，保存按钮可滚到。
- 横屏：不强行支持完整双栏；先保证竖屏可用，横屏做只读/简化视图。

## 信息不减少

移动端只是**重新组织**，不删除：

- 桌面左栏的全部读数 → 洞察账笺。
- 桌面右轨的缩放 → 双指缩放 + 星轨拖动。
- 桌面顶栏的账本/月份/记一笔 → 顶栏 + 底部导航。
- 桌面星轨的点击/拖动/今天 → 移动星轨相同。
- 桌面记一笔的全部字段 → 移动账笺。

## 生产实现 M1a（当前分支）

- `web/` 在 `≤760px` 启用移动布局：隐藏左栏/右轨/缩放条，星图全屏。
- 顶部：现有顶栏收成两行 + 移动结余条（账期/结余/支出/收入/读数），数值与左栏同源；月总额在结余条“支出”里，不重复。
- 底部：移动导航「星图 / 读数 / ＋记一笔」；读数把现有左栏 DOM 作为底部账笺打开。
- 星轨固定在底部导航上方；选中月居中，收入标签缩短避免重叠；头部「日/月/年/全部」四档可切。
- 星图单指平移、双指 pinch 缩放；桌面滚轮/右轨不变。
- 安全区：顶栏 `safe-area-inset-top`，底部导航/星轨/读数账笺 `safe-area-inset-bottom`；浮层最大高度受视口约束。
- 软键盘：`visualViewport` 同步 `--vvh`，记一笔账笺随可视视口缩短，保存区可达。
- 横屏 ≥761px 宽：回退桌面三栏骨架，顶栏 56px、星轨 110px；不硬塞竖屏底栏。
- 记一笔直接复用现有浮层。

## 后续

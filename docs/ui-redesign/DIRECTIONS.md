# 阶段 1 · 中式星图方向

> 目标是去掉「深色玻璃 + 青紫渐变 + 发光圆球」的 AI 感，找到更贴合「星账」的视觉世界。
> 这一阶段只做方向 style tile，不改生产 UI。用户选定后才写 `DESIGN.md` 并进入逐界面重构。

## 参考母题

- **敦煌星图**（唐）：墨线星点、星官分组、二十八宿的环形秩序；不是满天随机粒子。
- **苏州石刻天文图**（南宋）：刻线、星点大小、碑拓的高对比；适合做「星等」与「刻度」。
- **浑仪 / 简仪**：铜环、刻度、瞄准管；适合做右轨、缩放、时间轴等「仪器控件」。
- **宋代刻本 / 星图题签**：宋体、竖排题名、细双线、朱砂印；适合做标签与浮层。
- **矿物颜料**：石青、石绿、朱砂、藤黄、蛤白、墨、金/铜；作为少量强调，而不是全屏渐变。
- **反参考**：磨砂玻璃、青紫渐变、发光文字、卡片套卡片、通用 KPI 仪表盘、国潮贴皮（灯笼/龙纹/祥云/书法堆砌）。

## 三个方向

### A · 绢本星图（推荐）

- **一句话**：把界面做成一张深色绢本上的星图，数据是墨点与细线，控件是题签与朱砂印。
- **地面/材质**：深墨蓝黑底、近不透明绢面、细发丝线、轻微纸纹；没有 backdrop blur、没有发光球。
- **颜色**：墨、蛤白、朱砂、石青、石绿、少量金；tag 自带颜色是画面里主要饱和色。
- **字体**：宋体/思源宋体做标题与星官名；人文无衬线做操作；金额用等宽数字。
- **构图**：顶栏是横向题签，左面板是页边注记，星轨是横向刻度，右轨是细长的观测尺。
- **星形**：小墨点 + 极细十字星芒 + 金额决定星等；收入用石绿空心菱形/环。
- **适合**：最贴近现有「星账」叙事，也最容易保留信息量与图谱逻辑。
- **风险**：如果只换颜色不换排版，会变成「深色版旧界面」；必须同时重做栅格、字体和控件质感。

### B · 浑仪铜鉴

- **一句话**：界面像一台夜间使用的浑仪，铜环、刻度、读数，星图只是镜中的投影。
- **地面/材质**：近黑石墨、失光黄铜、氧化铜绿；双线刻度、细刻槽、少量铆点；没有圆角卡片。
- **颜色**：石墨黑、旧铜、铜绿、星白、少量朱砂；比 A 更冷、更技术。
- **字体**：窄体/无衬线标题，宽字距小标签，等宽数字；宋体只用于少量题名。
- **构图**：顶栏是仪器横梁；左面板是竖排读数；右轨是大弧/刻度环；缩放是校准盘。
- **星形**：双环节点、刻度珠、细铜线；收入用另一种环。
- **适合**：想要更「工具」、更少文学感的用户；信息密度可以做得更精密。
- **风险**：容易滑向「科幻 HUD」；必须靠真实刻度与铜材质压住，不要用霓虹。

### C · 碑拓星图

- **一句话**：像从石碑上拓下来的一张星图，黑白分明，朱砂只做印。
- **地面/材质**：炭黑石面、纸纹/拓痕、高对比蛤白刻线；浮层可用浅色拓纸反差。
- **颜色**：炭黑、蛤白、朱砂、少量石绿；几乎不用第三种彩色。
- **字体**：宋体/楷体为主，标题厚重，数字等宽；减少无衬线。
- **构图**：顶栏是碑额横带；左面板是铭文块；星轨是刻线；控件像刻出来的凹槽。
- **星形**：白点 + 刻线，收入用留白环；共享线用断续刻痕。
- **适合**：最有个性、最有「中式」分量；适合强调「账本刻在石上」的长期感。
- **风险**：日常高频记账可能显得过重；浅色浮层与深色主体的切换要控制好。

## 推荐与选择标准

- 推荐 **A · 绢本星图** 作为主轴，吸收 B 的刻度/仪器感；C 作为更大胆的备选。
- 选择时只看三件事：
  1. 是否一眼像「星账」，而不是任何深色仪表盘；
  2. 信息密度是否仍能承载所有账目/标签/金额；
  3. 是否愿意每天打开它记一笔。
- 选定后写 `DESIGN.md`：tokens、字体、材质、星形语法、组件规则、动效；再进入阶段 2 的第一项。

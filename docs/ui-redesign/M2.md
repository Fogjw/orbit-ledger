# M2 · Android APK 与模拟器链路

> 状态：M2a（debug APK 构建）+ M2b（Android Emulator WebView E2E）已跑通；M2c（release 签名/真机）未做。

## 已落地

- `mobile/` 独立 Capacitor 工程，复用 `webapp/dist`，不复制业务代码。
- `@capacitor/core` / `@capacitor/android` / `@capacitor/cli` 8.6.2；Android compileSdk 36、minSdk 24、targetSdk 36。
- debug 包开启 WebView DevTools（只在 `FLAG_DEBUGGABLE` 时），E2E 通过 CDP 读真实 WebView DOM，不是 Chromium 视口仿真。
- `webapp/boot.js` 记住“浏览器存储”选择：Android/网页第二次启动不再回到 gate；这是 Android 重启测试抓到的真实 bug。
- `.github/workflows/android.yml`：
  - `build-apk`：Node 24 + JDK 21 + runner 预装 Android SDK，Gradle 构建 debug APK。
  - `emulator-e2e`：API 35 / Pixel 6 / KVM，安装 APK，跑 WebView smoke，上传截图。
- Android 硬件返回键：`MainActivity.onBackPressed()` → `window.__orbitBack()`，先关浮层，根视图才退出。
- 品牌图标/启动图：石墨底、黄铜轨道、主星；生成脚本 `mobile/tools/make-branding.py`。
- Android 备份导出/导入：原生 `OrbitAndroid.shareBackup` / `pickBackup` 桥；JSON 仍与桌面互通。
- 签名 CD：`android-release.yml` 在 Release 成功后自动挂 APK/AAB 到同一 tag；1.2.2 起生效。
- release 签名：`ORBIT_KEYSTORE_*` 环境变量 + `android-release.yml` secrets；无 keystore 不伪造发布包。
- `mobile/test/android-smoke.mjs`：adb 启动 + WebView CDP，断言：
  - 首次 gate 只有浏览器存储；Android WebView 不显示无效的“真实文件”入口；
  - 进入移动壳；
  - 打开读数账笺；
  - 记一笔 ¥12.34；
  - 系统旋转到横屏，回到三栏；
  - 返回键关闭读数账笺/记一笔，app 不退出；
  - force-stop 后重开，12.34 从 IndexedDB 恢复，且不再出现 gate。
- 截图：`android-main` / `android-after-add` / `android-landscape` / `android-relaunch`，由 CI artifact 上传。

## 本地/CI 命令

CI（推荐，不需要本机 Android SDK）：

```bash
# GitHub Actions → Android APK + WebView E2E
```

本地只构建 APK（需要 JDK 21、Android SDK 36）：

```bash
npm ci
npm run build:web
npm ci --prefix mobile
cd mobile && npx cap sync android
cd android && ./gradlew assembleDebug --no-daemon
# 产物：mobile/android/app/build/outputs/apk/debug/app-debug.apk
```

当前开发机没有 JDK/Android SDK/KVM，所以本地不产出 APK；APK 与模拟器测试以 CI 为准。
